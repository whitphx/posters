# Project instructions

## Poster design

- Every visual element must communicate content, hierarchy, grouping, a relationship, or a flow.
- Do not add decorative kicker text, rules, rails, patterns, shapes, or marks solely to create visual interest or fill space.
- Do not use a line as a substitute for clear typography and spacing. Add one only when it separates content or expresses a relationship.
- When an element has no informational purpose, omit it.
